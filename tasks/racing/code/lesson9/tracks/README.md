# Lesson 9 tracks

These are the original study's track pools (`study`, `dev`, `train`, `val`), written by `../gen_tracks.py`
and `../gen_pool.py`. Each `manifest_<role>.csv` lists every candidate seed, accepted or rejected, with the
reasons; `reference_margins_<role>.csv` is the output of `../check_references.py`.

The results in `../results/` were flown on these tracks.
